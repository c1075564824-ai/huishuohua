# 会说话

个人使用的口才与发声训练 H5。围绕四项核心能力，采用跟读、主动回忆、场景迁移和间隔复习。录音与进度只保存在当前设备。

## 当前版本

- 28 天四周训练包：说得清、说得实、说得当、说得稳。
- 每天三档：60 秒门槛版、5 分钟标准版、15 分钟完整版。
- 每课包含金句、气口标记、表达结构、关键词和现实迁移任务。
- 48 条实用句库，覆盖开场、过渡、总结、夸奖、感谢与敬酒、异议回应。
- 按第 1、3、7、14、30 天间隔安排复习。
- 支持录音、回放、导入本地录音或无录音复盘。

## 本机预览

在终端进入本目录后运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

麦克风只在 `localhost` 或 HTTPS 页面可用；直接双击 `index.html` 时通常无法录音。

## 微信使用

通过上面的 GitHub Pages 地址在微信中打开。不需要账号、后端或 API Key。建议使用微信浮窗或收藏。

## 数据说明

- 录音与练习记录保存在浏览器 IndexedDB。
- 不上传录音，不接入云端 AI。
- “复习”页支持导出、导入和清空本机数据。
- 更换浏览器、清除网站数据或删除应用后，本机记录可能丢失。
