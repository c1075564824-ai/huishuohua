# 会说话

个人使用的表达单点突破训练 H5。一次只练一篇经典范文，依次完成饱和背诵、结构锚定、变式打磨和三次迁移，通关后才解锁下一关。

## 当前版本

- 七关经典演讲范文，按难度强制逐关解锁。
- 每关统一四步：饱和背诵、结构锚定、变式打磨、迁移通关。
- 敬酒包 6 个固定对象样本，致辞包 5 个固定场景样本，支线独立、不能并行。
- 致辞包在主线第 1 关通关后开放，支线通关不改变主线解锁。
- 背诵要求连续三次脱稿无卡顿，卡顿一次即清零。
- 结构阶段必须完成顺序拼装和错误结构辨析。
- 变式阶段必须替换全部内容并保持原骨架。
- 迁移阶段必须通过三个不同职场命题。
- 示范语音优先选择中文男声，支持 0.8x、1.0x、1.5x，段落之间保留停顿；支持跟读录音自检。
- 首页、七关和记录三个主入口。

## 本机预览

在终端进入本目录后运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

麦克风只在 `localhost` 或 HTTPS 页面可用；直接双击 `index.html` 时通常无法录音。

## 数据说明

- 关卡进度与过关记录保存在浏览器 IndexedDB。
- 不上传数据，不接入云端 AI。
- “记录”页支持导出、导入和清空本机数据。
- 更换浏览器、清除网站数据或删除应用后，本机记录可能丢失。
