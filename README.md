# 会说话

个人使用的口才与发声练习 H5。录音和历史记录默认只保存在当前设备。

## 微信入口

https://c1075564824-ai.github.io/huishuohua/

## 本机预览

在终端进入本目录后运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

麦克风只在 `localhost` 或 HTTPS 页面可用；直接双击 `index.html` 时通常无法录音。

## 微信使用

通过上面的 GitHub Pages 地址在微信中打开。首版不使用后端，也不需要 API Key。

## 数据说明

- 录音与练习记录保存在浏览器 IndexedDB。
- 不上传录音，不接入云端 AI。
- “我的记录”支持导出 JSON 和清空本机数据。
- 更换浏览器、清除网站数据或删除应用后，本机记录可能丢失。
